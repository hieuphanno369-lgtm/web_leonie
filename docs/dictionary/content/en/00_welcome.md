# ⬡ Leonie — Where Are You?

> **Leonie** is your personal data analysis workspace. 8 areas, each with its own purpose.

## What do you want to do?

| I want to...                              | Go here           | Note                           |
|-------------------------------------------|-------------------|--------------------------------|
| Analyse / forecast data                   | ◈ Data Studio     | The core of the entire app     |
| Track today's work                        | ⬡ Tasks           | Deadline + priority + checklist|
| View performance & reports                | ◎ Performance     | Charts, burndown, tag breakdown|
| Read & classify Outlook emails            | ◉ Email           | AI summary + reply suggestions |

| Check running pipelines                   | ◉ Pipeline        | Scheduler, Discord health      |

---

## ◈ Data Studio is the hub

All analysis starts from **Data Studio**. It has 4 tools:

```
Upload data → [Data Explorer]  → understand what your data contains
Write SQL   → [SQL → Obsidian] → analyse + save as a note
Run ML      → [ML Studio]      → AI forecasting / clustering
Save query  → [Snippets]       → reuse frequently used SQL
```

---

## Where to start?

**First time:**
1. Go to **◈ Data Studio** → choose **⚗ ML Studio**
2. Read the *"What is ML Studio?"* section in this Dictionary
3. Upload a CSV/Excel file → follow the 8-step pipeline

**Already familiar, need a quick reference:**
- Use the search bar above → type a term (e.g. `sarimax`, `mape`, `task`)
- Or choose a filter chip **ML** / **Tools** on the left
