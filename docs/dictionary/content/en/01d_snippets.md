# ◇ SQL Snippets

> Your personal SQL library — save frequently used queries and retrieve them quickly.

## What is it for?

Instead of rewriting the same SQL query every week, save it once in Snippets and copy it out when needed.

## Features

| Feature       | Description                                        |
|---------------|----------------------------------------------------|
| Add snippet   | Title + SQL content + category tag                 |
| Search        | Search by title or SQL content                     |
| Copy          | 1-click copy SQL to clipboard                      |
| Delete        | Remove snippets that are no longer needed          |
| Categories    | Group snippets by type (aggregate, filter, join…)  |

## Tips

- Name snippets clearly: `"Revenue by channel this month"` is better than `"query1"`
- Use categories to group: `sfdc` (Salesforce), `fabric` (Data warehouse), `common`
- Snippets are stored at `data/snippets.json` — you can back up this file
