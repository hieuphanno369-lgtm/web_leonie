# ⬡ Tasks

> Track work by priority, deadline, and AI checklist.

## What is it for?

Manage daily tasks: add tasks, assign priority, set deadlines, mark as complete.

## Priority levels

| Level    | Colour      | Use when                                      |
|----------|-------------|-----------------------------------------------|
| ◈ High   | Red         | Due today or blocking someone else            |
| ◆ Medium | Orange      | Needs to be done this week                    |
| ◇ Low    | Green       | Backlog, do when time allows                  |
| ⚡ Ad-hoc | Light blue  | Spontaneous, no fixed deadline                |

## Key features

- **Global search bar**: filter tasks by name or tag (`#urgent`, `#sf`)
- **AI Checklist**: for complex tasks, click Generate → AI creates sub-checklist
- **Recurring tasks**: repeats monthly or yearly
- **Discord reminder**: reminders via Discord at 09:00 and 13:30

## Tips

- Overdue tasks show a red badge in the sidebar
- Click on a task to edit inline — no need to open a separate form
- Use the `#sf` tag for Salesforce-related tasks to filter quickly
