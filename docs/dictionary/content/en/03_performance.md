# ◎ Performance

> Visual reports on completed work: burndown, priority distribution, tag analysis.

## Available charts

| Chart              | How to read it                                            |
|--------------------|-----------------------------------------------------------|
| Priority breakdown | Pie chart — ratio of High/Medium/Low/Ad-hoc               |
| Status breakdown   | Done vs Active — measures what % is complete              |
| Burndown chart     | Tasks completed per day — upward trend is good            |
| Tag analysis       | Which tags appear most often in your tasks                |

## When to use?

- End of week: check if burndown is steady or all crammed at the end
- End of month: priority breakdown — too many High means you're overwhelmed
- When you want to know where you spend most of your time (tag analysis)
