# ⏱ Focus Timer

> Pomodoro timer — 25 minutes work, 5 minutes rest. Stay focused, avoid distractions.

## How to use

1. Enter the name of the task you're working on (optional)
2. Click Start → 25-minute countdown begins
3. When time is up → app notifies → take a 5-minute break
4. Repeat — after 4 pomodoros take a longer 15–30 minute break

## Why use Pomodoro?

The human brain struggles to concentrate continuously for more than 30 minutes. Pomodoro breaks time into short sprints — making big tasks less daunting and easier to start.

## Tips

- Turn off all notifications before starting the timer
- Write the current task in the text box so you remember what you were doing after the break
- If interrupted mid-session → click Reset and start again rather than continuing the countdown
