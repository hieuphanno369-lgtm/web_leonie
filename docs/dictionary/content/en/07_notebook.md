# ⬡ Notebook

> Integrated JupyterLab — write Python, run code, take meeting notes.

## What is it for?

- Write and run exploratory Python code without opening a terminal
- Take meeting notes in Markdown format
- Quickly test a code snippet before adding it to a main module

## Recommended stack (DA/DS/DE)

| Type of work       | Common libraries                            |
|--------------------|---------------------------------------------|
| Data Analysis      | polars, pandas, plotly                      |
| Machine Learning   | scikit-learn, xgboost, statsmodels          |
| Data Engineering   | dbt, sqlalchemy, pyarrow                    |
| Visualisation      | plotly, matplotlib, seaborn                 |

## Tips

- Notebooks are saved to `D:\ai_brain\` (Obsidian vault) — automatically available in Obsidian
- Use magic command `%%time` to measure how long each cell takes to run
- Restart the kernel if memory usage is high (usually after loading large files)
