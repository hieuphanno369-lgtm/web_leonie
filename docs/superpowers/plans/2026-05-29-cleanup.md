## Task 2: Fix SPA catch-all bug in main.py

**Files:**
- Modify: `backend/main.py`

**Context:** `async def serve_spa(_: str)` — FastAPI treats `_: str` as a required *query* parameter named `_`, not a path variable. Any request to an unmatched path (e.g., `/some/page`) gets 422 "Field required" unless `?_=something` is passed. Fix: rename the parameter to match the path variable and give it a default value.

- [ ] **Step 1: Fix the catch-all handler**

In `backend/main.py`, find and replace:

```python
# BEFORE (line ~74):
    @app.get("/{full_path:path}")
    async def serve_spa(_: str):
        return FileResponse(str(DIST / "index.html"))
```

```python
# AFTER:
    @app.get("/{full_path:path}")
    async def serve_spa(_full_path: str = ""):
        return FileResponse(str(DIST / "index.html"))
```

- [ ] **Step 2: Verify the fix manually**

Start the backend (if not running) and test:

```bash

.venv/Scripts/python -c "

r = c.get('/some/nonexistent/path')

print('Body starts with:', r.text[:30])
"
```

Expected: status 200 (returns index.html) or 404 if DIST does not exist, never 422.
